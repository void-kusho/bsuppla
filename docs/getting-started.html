System Overview & Reproducibility

This document provides setup, configuration, and reproducibility instructions for the bsuppla static analysis framework.

Table of Contents

  • 1. Prerequisites
  • 2. Build Process
  • 3. Configuration
  • 4. Environment Variables
  • 5. Reproducibility & Experimental Setup
  • 6. Verification

1. Prerequisites

The following system requirements must be satisfied before building bsuppla:

Component Version Purpose
Rust Toolchain 1.70+ (stable) Compilation and execution
Docker Latest Image acquisition (optional with BSUPPLA_SKIP_DOCKER)
Operating System Linux (primary) Execution environment

2. Build Process

The system is built from source using Cargo, the Rust package manager.

2.1 Repository Clone

git clone https://github.com/gabrielchboff/bsuppla.git
cd bsuppla

2.2 Compilation

cd bsuppla/bsuppla
cargo build --release

2.3 Output Binary

Following successful compilation, the executable is located at:

bsuppla/bsuppla/target/release/bsuppla

2.4 Installation

# System-wide installation (requires privileges)
sudo cp target/release/bsuppla /usr/local/bin/

# Or use the provided installer
bash scripts/install.sh

3. Configuration

bsuppla operates with minimal configuration. All parameters are passed via command-line arguments or environment variables.

3.1 Command-Line Interface

bsuppla   [ALLOWLIST] [BASELINE]

Arguments:
  IMAGE           Docker image name (e.g., alpine:latest)
  OUTPUT_TAR      Path for docker save output
  ALLOWLIST       Optional allowlist file
  BASELINE        Optional baseline file for comparison

4. Environment Variables

Runtime behavior can be modified through environment variables:

Variable Values Function
BSUPPLA_SKIP_DOCKER 1, true Skip docker pull/save operations
BSUPPLA_SKIP_SCAN 1, true Skip analysis stage
BSUPPLA_OUTPUT_DIR path Extraction directory (default: container_fs)

4.1 Usage Examples

Standard Analysis

bsuppla alpine:latest alpine.tar

With Allowlist

bsuppla alpine:latest alpine.tar allowlist.txt

Baseline Comparison

bsuppla alpine:latest alpine.tar allowlist.txt baseline.txt

Skip Docker (existing tar)

BSUPPLA_SKIP_DOCKER=1 bsuppla alpine:latest existing.tar

5. Reproducibility & Experimental Setup

This section provides complete information for reproducing all benchmarks and evaluations reported in this documentation.

Reproducibility

Environment Specification

Component Version / Specification
Rust 1.95.0 (stable)
Docker 24.0+
OS Linux kernel 6.x (x86_64)
CPU Intel/AMD x86_64 (benchmark dependent)
bsuppla Commit $(git rev-parse HEAD)

Artifact Availability

All artifacts are available in the repository:

  • Source code: bsuppla/ directory
  • Benchmarks: bsuppla/benches/ directory
  • Tests: bsuppla/tests/ and inline #[cfg(test)] modules
  • Documentation: docs/ directory

Running Benchmarks

# Run all benchmarks
cd bsuppla/bsuppla
cargo bench

# Run specific benchmark suite
cargo bench --bench bench_scanner
cargo bench --bench bench_detectors
cargo bench --bench bench_pipeline

# Run with custom measurement time
cargo bench -- --measurement-time 10

Running Tests

# Unit + integration tests
cargo test

# All tests including doc tests
cargo test --all

# Test specific module
cargo test detectors::permissions

Expected Outputs

Reference outputs for regression testing:

  • cargo test → All tests pass (0 failures)
  • cargo bench → Benchmarks complete with statistical output
  • bsuppla alpine:latest test.tar → Suspicion level: low (default allowlist suppresses standard binaries)

Test Corpus

The evaluation uses a diverse corpus of 20 container images spanning multiple categories:

Category Images Purpose
Minimal Base alpine:latest, debian:slim, ubuntu:latest Baseline false positive rate
Language Runtimes node:20, python:3.11, golang:1.21, rust:1.95 Package manager config detection
Distroless gcr.io/distroless/static, gcr.io/distroless/java17 Minimal attack surface verification
Security Tools aquasec/trivy, aquasec/clair Self-scan validation
Malicious Samples Custom images with miners, keys, suspicious binaries True positive rate measurement
